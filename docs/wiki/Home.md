# RoboDrummer Wiki

RoboDrummer is a real-time adaptive virtual drummer for jamming with one live guitarist. The source version is 0.4.0. Build targets are VST3, CLAP and Standalone, plus AU on macOS. See the [QA record](../QA.md) for qualification results and remaining checks.
