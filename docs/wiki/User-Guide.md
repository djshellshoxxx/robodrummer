# User Guide

- **Install:** see `docs/INSTALL.md`. Release notes: `docs/RELEASE_NOTES_0.4.0.md`.
- **In-app help:** the Help/About screen is generated from `docs/HELP.md`.
- **Modes:** lead at a fixed or host tempo, follow the guitarist's tempo and beat, or hybrid.
- **Optional MIDI control:** fills, next section, intensity, half/double time, crash, break, stop/resume, listening reset. Practice mode uses MIDI commands 51 to 55.
- **Tabs (0.4.0):** LIVE, KIT, DRUMMER, STYLE, SONG, PRACTICE, MIDI, ANALYSIS, SETTINGS.
- **Parameters:** `docs/PARAMETERS.md`.

Compliance and host testing status: `docs/COMPLIANCE.md` and `docs/QA.md`. The README notes that AU is a target,
not a verified deliverable.
