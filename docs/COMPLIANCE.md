# CDL Shared Audio Plugin Standard — compliance record

Applies to RoboDrummer 0.4.0. Standard: [`standards/CDL_PLUGIN_BASELINE.md`](standards/CDL_PLUGIN_BASELINE.md) (required baseline). Product specification: [`../SPEC.md`](../SPEC.md).

## Product profile (§1.2)

Hybrid **instrument plug-in + standalone application**. Targets: VST3 and CLAP (Windows, macOS, Linux), AU (macOS), Standalone. Standalone-only device settings (audio device, sample rate, buffer size) are provided by the JUCE standalone wrapper and are not duplicated inside the plug-in.

Buses: stereo guitar/analysis input (mono, stereo or disabled); stereo main output ("Drums + Monitor"); four optional stereo aux outputs (Kick, Snare, Toms, Hats + Cymbals), disabled by default. MIDI in and out. Latency 0 samples (reported). Tail 2 s.

## Compliance table (§1.3)

| Baseline area | Status | Notes |
|---|---|---|
| 2.1 Predictable controls | Implemented | Every control is labelled and bound to a parameter or command; toggles show state; commands show feedback. |
| 2.2 Parameter contract | Implemented | Stable IDs, documented in [`PARAMETERS.md`](PARAMETERS.md) (generated from code). Host automation ⇄ GUI via JUCE attachments. Audio-thread-originated changes (MIDI intensity, sections) are republished to the host from the message thread. |
| 2.3 Gestures | Implemented | Double-click resets a slider; tooltips can be turned off globally and their delay chosen (SETTINGS, Interface). Right-click (or Shift+F10) on every slider, choice and switch offers Reset to default, Copy value and Paste value; pasted text is validated (range for sliders, choice names or a plain index for choices, on/off/true/false/1/0 for switches) and a rejected paste changes nothing and fires no host gesture. MIDI Learn, Cancel MIDI Learn and Clear MIDI mapping appear only for parameters in the learn-target list. Combos and switches deliberately have no double-click reset (a double click would toggle them twice). Spec 15. |
| 2.4 Accessibility | Implemented (host key forwarding varies) | State is conveyed by text as well as colour (ON/OFF text beside meters, numeric read-outs, outlined bars, filled push toggles). Every parameter control has an accessibility title and description. A 2 px focus-ring overlay (shape, not colour alone) marks the keyboard-focused control; sliders take arrows, Page Up/Down, Home/End and Backspace/Delete, Ctrl+Tab cycles tabs, Escape closes Help or cancels Learn My Playing; the Help overlay traps focus. Options (SETTINGS, Interface): Reduce motion (5 Hz instead of 20 Hz refresh) and High-contrast outlines, persisted per user in settings.xml. Editor minimum 960×680, resizable to 1700×1200. Not done: the OS reduced-motion preference is not read (no cross-platform API; defaults to off) and the ANALYSIS onset scroll is slowed rather than frozen; some hosts do not forward keys to plug-in windows (all functions remain mouse-operable). Spec 17. |
| 3.1 Host responsibilities | Implemented | Plug-in never opens or configures audio devices. |
| 3.2 Real-time safety | Implemented | 0.4.0 additions (drum bus, transient shaper, riff lock, practice mode, MIDI capture, Auto Setup, auto meter, virtual limbs) use fixed storage and atomics only; capture export, temp files and Auto Setup finalization run on the message thread. No allocation/locks/I/O on the audio thread — verified by an allocation audit (0 allocations over 1500 blocks with aux buses, reverb, MIDI clock, calibration). Variable and zero-length blocks, 11–192 kHz sample rates, NaN/Inf input covered by the harness. Latency 0, `ScopedNoDenormals`, tail 2 s. |
| 3.3 Formats, buses, transport | Implemented | See profile. Stopped transport silences new hits (Drummer Leads); missing host tempo falls back to Internal BPM; seeks/loops re-sync the bar position (`JamEngine::syncToPpq`). Internal-BPM-only and MIDI-clock tempo sources are available. |
| 3.4 Bypass, levels, meters | Implemented | Instrument: no MIDI → free-running drummer by design; All Sound Off / All Notes Off silence the sampler. Meters: "Input level" = analysis signal after gain/gate (dBFS peak); "Output" = main mix peak. |
| 4.1 Host state | Implemented | State version 4; v1, v2 and v3 migrate (parameters absent from an older session reset to their defaults, so old sessions sound identical); new parameters are NaN/range sanitised on restore; a running practice session and an Auto Setup undo are never restored; malformed, truncated and mutated state is fuzzed (400 mutations + 100 garbage blobs) without crashes or out-of-range values. Non-parameter state: arrangement slots, MIDI map, drum map, user-kit folder path (not the samples). |
| 4.2 Presets | Implemented | Jam/Drummer/Style/Kit/Song/Analysis presets as XML in the user application-data folder; atomic (values applied only after the file parsed); factory presets listed in the UI; Jam factory presets are also host programs. No A/B compare (optional). |
| 4.3 File loading | Implemented | User kits: WAV/AIFF/FLAC, mono/stereo, any sample rate (resampled), ≤ 20 s per file; unrecognised/unreadable files are skipped with a status line; loading is asynchronous with fallback to the built-in kit. No audio export. |
| 5 MIDI/automation | Implemented | Note-on/off, velocity, channel handling, All Notes Off documented in help; MIDI Learn shows armed state, mapping result, can be cancelled/cleared/reset; conflicting mappings are resolved by replacing the previous binding. Controller-over-automation precedence: last writer wins (the CC updates the host parameter). Invalid/dense streams fuzzed. |
| 6 Visual identity | Implemented | CDL palette (`EditorWidgets.h`), dark layout; Inter is not bundled — platform sans-serif fallback. The editor fits its 960×680 minimum on all 9 tabs (checked by the harness for clipping, zero-size and off-screen controls, and by screenshot review). |
| 7.1 Options | Implemented | Show tooltips, tooltip delay (300/600/1000 ms), Reduce motion, High-contrast outlines; stored read-modify-write in `settings.xml` (unknown attributes survive, corrupt files fall back to defaults). |
| 7.2 Help/About | Implemented | HELP button opens a sectioned, scrollable guide generated at build time from `docs/HELP.md` (so the repository document and the UI cannot drift), with version and build date, formats (VST3, CLAP, AU on macOS, Standalone), the privacy statement, links to the Circuit Drift Labs site and the issue tracker, COPY DIAGNOSTICS (clipboard only) and SHOW TOUR. SETTINGS shows a short About too. |
| 8 Privacy/security | Implemented | **No network access, telemetry, analytics, licensing or update checks.** Parsers validate ranges and bound sizes; paths are handled through `juce::File`. |
| 9 Documentation | Implemented | README, `docs/INSTALL.md`, `docs/JUCE_BUILD.md`, `docs/PARAMETERS.md`, `docs/QA.md`, `docs/feature-audit/`. |
| 8.1 Files written (0.4.0) | Implemented | MIDI capture drag files are written only on the user's request to `<system temp>/RoboDrummer/<instance>/` (std::filesystem), kept to the most recent 20 per instance, and stale files (older than 24 h, or left by a crashed instance) are removed at start-up. No other files are created outside user-chosen locations. |
| 7.3 First run / learn (0.4.0) | Implemented | Learn My Playing: running card (progress, prompt text, input peak, Cancel/Escape), review card with per-field checkboxes, Apply/Cancel, Undo Auto Setup, failure reasons with Try again. Optional first-run tour: a small skippable card that never blocks the controls, restartable from HELP and SETTINGS; seen-state in `settings.xml`. |
| 10 Required links | Implemented | Standard stored in `docs/standards/`, linked from README and SPEC. |
